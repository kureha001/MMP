# 【プロローグ：ようこそ、株式会社MMPへ】

ここに、ちょっと変わったサービスを提供する会社があります。
その名も「株式会社MMP」。

「様々な機器をお客様で共同利用する」、これがMMPが扱うサービスです。
機器を貸し出すのではなく、お客様に変わり社員が「**代理で操作し、結果を報告**」します。
お客様は、「あの機器をこう操作してほしい」と注文し、結果を受け取るだけ。

この会社には、複数の部門が協力して成り立っています。

### 接客部門
まずはお客様から真っ先に注文を受けるための窓口です。
お客様の多彩な要望に応えるため、多く「受注方法」があります。
受注方法ごとに窓口と担当者が控えています。
社内では、部門長を営業部長、担当者を営業マンと呼んでいます。

### 通信設備部門
受注と納品を裏から支えるインフラ部隊です。
多彩な受注方法が用いる、通信基盤を整えています。
社内では、部門長を設備長、担当者を技術者と呼んでいます。

### 製造部門
会社の商品を生み出す職人集団です。
社内では工場と呼ばれています。
狭い作業場には、多数の機器がズラリと並びます。
機器ごとに専任の熟練職人が「お客様の要望」に応えます。
社内では、部門長を設備部長、担当者を職人と呼んでいます。
