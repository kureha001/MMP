## 【第1話：朝の出社と営業開始】

それでは、この会社の朝の準備から実際の営業がされる1日を見てみましょう。

#### 【オフィスの目覚め】
朝一番、社長の出社です。
おもむろに棚から伝票を取り出します。
社員たちが使う注文書です。

##### 社長は一息つくと、通信設備部門へと足を運びます。
「現場が稼働できるよう準備を頼む」と、設備長に声をかけた。
設備長はすぐに、技術者たちを集めた。
「全員いるな...よし、仕事にかかるぞ！」と力強く号令を飛ばした。
静かに、そして手際よく、通信デバイスが次々と起動していきます。
やがてサーバルームは、キラキラと輝く赤や緑のLEDで包まれます。

##### 次に社長が向かったのは、製造部門。
「いつでも機器が動くよう準備してくれ」と、工場長に声をかけた。
工場長は職人たち達を集め、「機器の傍で待機してくれ」と指示をだす。
職人たちは、受け持つ機器のウォームアップを開始。
工場内には、空調ファンと機器が目覚める音が響き渡ります。

##### そして最後に社長は、接客部門へと向かう。
「今日も忙しくなるぞ！態勢を整えてくれ」と、フロア中に響く声で活を入れます。
部門長も負けじと大声で返事を返し、ずらりと並んだ窓口へ担当者をすばやく配置。

##### ようやく社長室に戻る。
全部門の準備が整ったのを見届けた社長は、大きくうなずいた。
そして、時計に目を運び「よし、これより営業開始だ！」
工場からは、元気なファンファーレが響いてきた。

```
（システムとの対応解説）
- 社長が用意した注文書 ＝ スケッチ冒頭のコンテキスト（データ構造）の実態化
- 社長の出社と各部門への指示 ＝ main.cpp の起動と各マネージャーの setup() 呼び出し
- 通信設備部門：技術者たちを集め ＝ 通信デバイスの実体化(コンストラクタ)と初期化キック (INIT())
- 製造部門：職人たちを集め ＝ 機能モジュールの実体化(コンストラクタ)と初期化キック (INIT())
- 接客部門：窓口へ担当者を配置 ＝ 通信アダプタの実体化(コンストラクタ)と初期化キック (INIT())
- 社長による接客部門長への繰り返し指示 ＝ loop() 内での繰り返し処理(HANDLE())
- 接客部門：接客作業を止めて社内注文 ＝ 溜まったキューを消化(通信アダプタのhandle())
```

#### 【動き出したオフィスの日常】

営業が開始すると、社長は繰り返し営業部長に指示を出します。
営業部長は各窓口の巡回し、（営業活動が滞らぬよう）次々と指示を出します。

部門長がある窓口にやってきました。
**接客対応**をいったん止めて、**社内注文を出す**よう、営業マンに指示します。
溜め込んだ**受注メモから注文書を起票**し、製造部門へ送ります。

工場長が注文書を確認すると、**該当機器の職人**を呼出します。
職人は注文書とおりに**機器を操作**し、**結果を記入**。
工場長はすぐさま、接客担当へ注文書を送り返します。

営業マンは受け取った注文書を見ながら、**お客様へ結果報告**。
...すぐに、次の注文メモを手を掛けます。

すべての注文メモを捌き終えると、営業部長は「ご苦労」とつぶやきながら隣の窓口へと去っていきます。それを見届けた営業マンは、**接客対応に戻り**ました。

```
（システムとの対応解説）
- 接客対応 ＝ 非同期でリクエストをキュー登録
- 社内注文を出す ＝ ポーリング処理でキューを取り出し、コマンド実行を依頼
- 受注メモから注文書を起票 ＝ キューの内容をコンテキストに転記
- 該当機器の職人 ＝ 該当する機能モジュール
- 機器を操作 ＝ 機能モジュールのコマンド実行
- 結果を記入 ＝ 処理結果をコンテキストに反映
- お客様へ結果報告 ＝ 接続識別子をもとに処理結果を送信
```
